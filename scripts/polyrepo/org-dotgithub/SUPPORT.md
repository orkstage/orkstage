# Getting help

| You want to | Go to |
|---|---|
| Learn how OrkStage works or how to set it up | [Documentation](https://orkstage.io/docs) |
| Ask a question or share an idea | [GitHub Discussions](https://github.com/orgs/orkstage/discussions) |
| Report a bug | The issues of the repository that owns the code (the issue forms help you choose) |
| Request a feature | A feature request issue, or a discussion for early ideas |
| Report a vulnerability | Privately, as described in [SECURITY.md](SECURITY.md) |
| Ask about Enterprise features or support | hello@orkstage.io |

Community support is given on a best effort basis by maintainers and other users. When you ask,
include the component, how you run it (the Docker Compose quickstart, from source, or something
else), the provider (AWS, MiniStack or simulated) and the relevant logs with secrets removed.
