# orkstage/.github

Organization defaults for every OrkStage repository:

| File | Purpose |
|---|---|
| [`profile/README.md`](profile/README.md) | The page shown at github.com/orkstage |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to contribute, in any repository |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Contributor Covenant 2.1, adapted |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability |
| [`SUPPORT.md`](SUPPORT.md) | Where to ask for help |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Issue forms for bugs and feature requests |
| [`.github/pull_request_template.md`](.github/pull_request_template.md) | Pull request checklist |

GitHub uses these files for any repository in the organization that does not have its own file
of the same type. They only apply, and the profile only shows, while this repository is public.

This repository is generated from `scripts/polyrepo/org-dotgithub/` in the development
monorepo by `scripts/polyrepo/split.sh`.
