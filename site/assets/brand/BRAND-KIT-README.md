# OrkStage Brand Kit v3

This package is rebuilt from the exact approved OrkStage logo supplied in the conversation (`Neon Orc Tech Logo Banner(1).png`).

## Brand palette
- Acid Mint / Neon Teal: `#00F29B`
- Deep Cyber Obsidian: `#0D0E12`
- Obsidian / Slate: `#1A1D26`
- Metallic Light: `#E2E8F0`
- Light UI background: `#FFFFFF`

## Variants
- Complete combination mark — dark/light
- Symbol/mascot only — dark/light
- Wordmark only — dark/light
- Transparent versions of each
- Favicon/app-icon PNG sizes: 16, 32, 48, 64, 128, 180, 192, 256 and 512
- SVG, PNG and JPEG exports

## Fidelity note
The SVG exports are self-contained SVG wrappers around source-derived transparent PNG masters. This choice intentionally preserves the approved generated artwork exactly instead of substituting a different hand-redrawn mascot or typography.

## Usage
Use the complete logo for site headers, product navigation and documentation. Use the mark alone for favicon, mobile navigation, application tiles and compact dashboards. Keep the mark undistorted and preserve clear space around the logo. Do not recolor, rotate, stretch, or add extra effects.

## Correction in v3
The symbol-only mark was recropped directly from the approved source so no portion of the `OrkStage` wordmark remains in the mark/favicons.
