## Planned: focused repositories

The split keeps history (`git subtree split` per folder, `scripts/polyrepo/split.sh`). Shared code
becomes **versioned packages**; git submodules are used only in the meta repository.

| Repository | Contents | Publishes | License |
|---|---|---|---|
| `orkstage` | API, worker, packages, `ee/`, platform image, docs | `@orkstage/contracts`, `/authorization`, `/templates`, `/domain`; `ghcr.io/orkstage/platform` | AGPL-3.0 + `ee/` |
| `orkstage-console` | The console (`apps/web`) | `ghcr.io/orkstage/console` | AGPL-3.0 + `ee/` |
| `orkstage-cli` | `ork` and the scan engine | Signed `ork` binaries, `@orkstage/scan` (WASM), Homebrew / Scoop / winget manifests | AGPL-3.0 |
| `orkstage-modules` | OpenTofu modules, runner image | Git tags `vX.Y.Z`, `ghcr.io/orkstage/tofu-runner:<tag>` | Apache-2.0 |
| `orkstage-site` | This site | Static site on S3 + CloudFront (orkstage.io) | MIT code, CC BY 4.0 content |
| `orkstage-dev` | Meta repository: submodules, compose, scripts | | MIT |

```text
orkstage-console ──npm──▶ @orkstage/contracts, /authorization, /templates, /domain
orkstage (api)   ──npm──▶ @orkstage/scan (from orkstage-cli)
orkstage (worker)──image─▶ ghcr.io/orkstage/tofu-runner:<modules tag>
orkstage-cli     ──HTTP──▶ OrkStage API (integration contract, OpenAPI)
orkstage-site    ──file──▶ OpenAPI JSON published by orkstage CI
orkstage-dev     ──git submodules──▶ all public repositories (pinned SHAs)
```

After the split, local development of the whole stack starts from `orkstage-dev`:

```bash
git clone --recurse-submodules git@github.com:orkstage/orkstage-dev.git
cd orkstage-dev
./dev.sh up
```
