## Planned: focused repositories

The split keeps the git history: `scripts/polyrepo/split.sh` runs `git subtree split` once per
folder. Shared code becomes **versioned packages**. Git submodules appear only in the meta
repository.

| Repository | Contents | Publishes | License |
|---|---|---|---|
| `orkstage` | API, worker, packages, `ee/`, platform image, docs | `@orkstage/contracts`, `/authorization`, `/templates` and `/domain`; `ghcr.io/orkstage/platform` | AGPL-3.0, plus `ee/` |
| `orkstage-console` | The console (`apps/web`) | `ghcr.io/orkstage/console` | AGPL-3.0, plus `ee/` |
| `orkstage-cli` | `ork` and the scan engine | Signed `ork` binaries, `@orkstage/scan` (WASM), manifests for Homebrew, Scoop and winget | AGPL-3.0 |
| `orkstage-modules` | OpenTofu modules and the runner image | Git tags `vX.Y.Z`, `ghcr.io/orkstage/tofu-runner:<tag>` | Apache-2.0 |
| `orkstage-site` | This site | Static site on S3 and CloudFront (orkstage.io) | MIT for code, CC BY 4.0 for content |
| `orkstage-dev` | Meta repository: submodules, Compose files, scripts | Nothing | MIT |
| `orkstage-licensing` | License signing service (private) | Nothing public | Proprietary |

How the repositories depend on each other:

```text
orkstage-console ──npm──▶ @orkstage/contracts, /authorization, /templates, /domain
orkstage (api)   ──npm──▶ @orkstage/scan (from orkstage-cli)
orkstage (worker)──image─▶ ghcr.io/orkstage/tofu-runner:<modules tag>
orkstage-cli     ──HTTP──▶ OrkStage API (integration contract, OpenAPI)
orkstage-site    ──file──▶ OpenAPI JSON published by orkstage CI
orkstage-dev     ──git submodules──▶ all public repositories (pinned SHAs)
```

After the split, local development of the whole stack starts from `orkstage-dev`:

```bash
git clone --recurse-submodules git@github.com:orkstage/orkstage-dev.git
cd orkstage-dev
./dev.sh up
```
