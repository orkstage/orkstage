<Callout type="warn" title="No tagged releases yet">
  OrkStage is developed on `main` and has not published versioned releases. This page describes the
  checks that run today and the release flow being prepared.
</Callout>

## What CI checks today

| Repository part | Checks |
|---|---|
| Platform (`.github/workflows/ci.yml`) | `pnpm install --frozen-lockfile`, build, typecheck, tests; migrations apply cleanly on Postgres and the seed is idempotent; `pnpm audit --audit-level high` |
| CLI (`cli/.github/workflows/ci.yml`) | `cargo fmt`, `clippy -D warnings`, tests; the committed WASM package is up to date and smoke-tested; release builds per target, with Authenticode (Windows) and Developer ID notarization (macOS) steps that run when signing secrets are configured |

## Planned release flow

1. **Versioning.** Semantic versions per repository. Breaking API changes get a new `/api/v2` route
   group; the template schema has its own version (`platform/v1`).
2. **Platform.** A tag builds and publishes `ghcr.io/orkstage/platform:<version>` and the shared
   packages (`@orkstage/contracts`, `/authorization`, `/templates`, `/domain`), and attaches the
   exported OpenAPI document to the release.
3. **Console.** `ghcr.io/orkstage/console:<version>`, pinned to a compatible contracts range.
4. **CLI.** Signed `ork` binaries for Linux (glibc and musl), macOS and Windows on x86-64 and arm64,
   `@orkstage/scan` on npm, then Homebrew, Scoop and winget manifests.
5. **Modules.** Git tags `vX.Y.Z` and `ghcr.io/orkstage/tofu-runner:<tag>`; the platform pins the
   runner tag so module changes are explicit upgrades.
6. **Compatibility matrix.** `orkstage-dev/COMPATIBILITY.md` lists the tested combination of
   versions; its CI runs the end-to-end suite against it.
7. **Site.** This site refreshes the API reference from the release's OpenAPI file and deploys to
   S3 + CloudFront.

## Changelog and security fixes

Each repository will keep a changelog per release. Security fixes are released as patch versions;
Enterprise customers are planned to receive advisories ahead of public disclosure.
