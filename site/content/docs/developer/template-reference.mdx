Templates describe **intent**, never provider resource blocks. The schema below is the source of
truth used by the API, the console builder and the CLI (`packages/templates/src/schema.ts`).

```yaml title="minimal template"
apiVersion: platform/v1
kind: EnvironmentTemplate
metadata:
  name: hello
  version: 1.0.0
  displayName: Hello
  profile: starter
spec:
  plans: [STARTER, GROWTH]
  placements:
    - name: primary
      providers: [aws]
  resources:
    - id: api
      type: compute.container-service
      image: catalog://hello-api
      port: 8080
      public: true
```

## Identifiers

Resource ids, slot names and variable names match `^[a-z][a-zA-Z0-9-]{0,39}$`: start with a
lowercase letter, then letters, digits and dashes, at most 40 characters.

## metadata

| Field | Type | Default | Notes |
|---|---|---|---|
| `name` | string | required | `^[a-z][a-z0-9-]{1,62}$`, unique per installation. |
| `version` | string | required | Semantic version `MAJOR.MINOR.PATCH`. |
| `displayName` | string | required | Shown in the console. |
| `description` | string | `""` | |
| `nonProduction` | boolean | `false` | Shows a warning; the `non-production-template` policy fails it for production instances. |
| `profile` | enum | required | `shared-sandbox`, `dedicated-sandbox`, `starter`, `growth`, `scale`. |

## spec

| Field | Type | Default | Notes |
|---|---|---|---|
| `plans` | enum[] | required, ≥ 1 | `FREE`, `SANDBOX`, `STARTER`, `GROWTH`, `SCALE`. |
| `placements` | slot[] | required, ≥ 1 | See [placements](#placements). |
| `variables` | variable[] | `[]` | See [variables](#variables). |
| `resources` | resource[] | required, ≥ 1 | See [resources](#resources). |
| `connectivity` | requirement[] | `[]` | See [connectivity](#connectivity). |
| `observability` | object | all on except `traces` | See [observability](#observability). |

## Placements

A placement slot is a named group of resources that an instance binds to one cloud target and region.

| Field | Type | Default | Notes |
|---|---|---|---|
| `name` | id | required | Referenced by resources' `placement`. |
| `description` | string | | |
| `providers` | enum[] | `[]` (any) | Allowed providers: `aws`, `azure`, `gcp`, `oci`, `mock`. |

```yaml
placements:
  - name: primary
    description: Application runtime, registry, ingress and DNS.
    providers: [aws, mock]
  - name: data
    description: Relational database.
    providers: [aws, azure, mock]
```

Networks bind implicitly only to resources in the same slot, so a database placed on another cloud
does not depend on the AWS VPC.

## Variables

| Field | Type | Default | Notes |
|---|---|---|---|
| `name` | id | required | |
| `description` | string | | |
| `type` | enum | required | `number`, `string`, `boolean`. |
| `default` | number, string or boolean | required | |
| `min`, `max` | number | | For numbers. |
| `allowed` | string[] | | For strings. |
| `target` | string | required | The field it sets, `<resourceId>.<field>`, for example `api.replicas`. |

```yaml
variables:
  - name: apiReplicas
    type: number
    default: 1
    min: 1
    max: 2
    target: api.replicas
  - name: databaseSize
    type: string
    default: small
    allowed: [micro, small, medium]
    target: database.size
```

## Resources

Every resource has these common fields, plus the fields of its `type`.

| Field | Type | Default | Notes |
|---|---|---|---|
| `id` | id | required | Unique in the template. Used in physical names: `co-<tenant>-<instance>-<id>`. |
| `type` | enum | required | One of the nine types below. |
| `placement` | id | `primary` | The slot this resource belongs to. |
| `implementation` | string | resolver's default | Preferred capability, e.g. `ecs-fargate`, `ecs-ec2`, `rds-postgres`. |
| `enabled` | boolean | `true` | Disabled resources stay in the template (so variables can toggle them) but are never provisioned. |
| `dependsOn` | id[] | `[]` | Explicit dependencies; implicit ones (network, ingress routes, DNS target) are added. |
| `overrides` | map of maps | | Provider-specific escape hatch, `{ aws: { … } }`. Less portable; admin only. |

### `network`

| Field | Type | Default | Notes |
|---|---|---|---|
| `strategy` | enum | `isolated` | `isolated` or `shared`. |
| `availabilityZones` | integer | `1` | 1 to 3. |
| `natGateway` | boolean | `false` | Private egress through NAT (one per AZ; adds cost). |

### `compute.container-service`

| Field | Type | Default | Notes |
|---|---|---|---|
| `image` | string | required | Catalog reference, e.g. `catalog://orders-api`, resolved to an immutable digest at deploy. |
| `replicas` | integer | `1` | 0 to 100. |
| `cpu` | number | `0.25` | vCPU, > 0 and ≤ 16. |
| `memoryMiB` | integer | `512` | 128 to 122880. |
| `port` | integer | | 1 to 65535. |
| `public` | boolean | `false` | Reachable through an ingress. |
| `healthCheckPath` | string | | Must start with `/`. |
| `autoscaling` | object | | `{ minReplicas, maxReplicas, targetCpuPercent (10–95) }`. |
| `critical` | boolean | `true` | Unhealthy critical components make the instance unhealthy. |

AWS implementations: `ecs-fargate` (default) and `ecs-ec2`.

<Callout>
  On AWS, `autoscaling` becomes an Application Auto Scaling target and a CPU target-tracking policy
  on the ECS service. MiniStack does not emulate autoscaling: there the service runs `replicas` fixed
  tasks and the deployment logs a warning.
</Callout>

### `container-registry`

| Field | Type | Default |
|---|---|---|
| `scanOnPush` | boolean | `true` |
| `immutableTags` | boolean | `true` |

### `database.postgresql`

| Field | Type | Default | Notes |
|---|---|---|---|
| `version` | string | `"17"` | Major version. |
| `size` | enum | `small` | `micro`, `small`, `medium`, `large`, `xlarge`. |
| `storageGiB` | integer | `20` | 1 to 16384. |
| `highAvailability` | enum | `none` | `none`, `same-zone`, `zone-redundant`. RDS offers zone-redundant (Multi-AZ) only. |
| `publicAccess` | boolean | `false` | The `no-public-database` policy fails `true`. |
| `backup` | object | `{ enabled: true, retentionDays: 7 }` | `retentionDays` 0 to 35; optional `recoveryPointObjectiveMinutes`. |
| `critical` | boolean | `true` | |

### `cache.redis`

| Field | Type | Default | Notes |
|---|---|---|---|
| `size` | enum | `micro` | `micro`, `small`, `medium`, `large`. |
| `replicas` | integer | `0` | 0 to 5. |
| `critical` | boolean | `false` | |

AWS implementation: ElastiCache with the Valkey engine (Redis OSS compatible).

### `queue`

| Field | Type | Default |
|---|---|---|
| `fifo` | boolean | `false` |
| `deadLetter` | boolean | `true` |
| `critical` | boolean | `false` |

### `object-storage`

| Field | Type | Default | Notes |
|---|---|---|---|
| `tier` | enum | `standard` | `standard`, `infrequent`, `archive`. |
| `versioning` | boolean | `false` | |
| `publicAccess` | boolean | `false` | The `no-public-storage` policy fails `true`. |
| `retentionDays` | integer | | Lifecycle expiration. |
| `critical` | boolean | `false` | |

### `ingress`

| Field | Type | Default | Notes |
|---|---|---|---|
| `routes` | route[] | required, ≥ 1 | `{ service: <container-service id>, pathPrefix: "/" }`. |
| `tls` | boolean | `true` | |

### `dns`

| Field | Type | Default | Notes |
|---|---|---|---|
| `target` | id | required | The ingress this name points to. |
| `subdomain` | boolean | `true` | A name under the platform zone, e.g. `production-acme.apps.example.com`. |
| `customDomain` | enum | `disabled` | `disabled`, `optional`, `required`. |

## Connectivity

| Field | Type | Default | Notes |
|---|---|---|---|
| `from`, `to` | id | required | Resource ids. |
| `protocol` | enum | required | `tcp`, `http`, `https`, `postgres`, `redis`, `amqp`. |
| `port` | integer | | |
| `mode` | enum | `private-preferred` | `private-required`, `private-preferred`, `secure`. |

`private-preferred` falls back to TLS over a public endpoint with allowlisting when the two resources
are on different clouds; `private-required` across clouds is rejected by the plan. See
[Reviewing plan & cost](/docs/user-guide/plan-and-cost/#connectivity).

```yaml
connectivity:
  - { from: api, to: database, protocol: postgres, port: 5432, mode: private-preferred }
  - { from: api, to: storage, protocol: https, mode: secure }
```

## Observability

| Field | Default |
|---|---|
| `logs` | `true` |
| `metrics` | `true` |
| `traces` | `false` |
| `uptime` | `true` |
| `alerts` | `true` |

## Example: the multi-cloud reference

```yaml title="06-multicloud-reference.yaml"
apiVersion: platform/v1
kind: EnvironmentTemplate
metadata:
  name: multicloud-reference
  version: 1.0.0
  displayName: Multi-cloud reference
  description: >
    API on AWS ECS Fargate behind an ALB with ECR and Route 53, Postgres on Azure Flexible Server,
    object storage on OCI. Bind every slot to the same AWS target for the AWS-only variant.
  profile: growth
spec:
  plans: [GROWTH, SCALE]
  placements:
    - name: primary
      description: Application runtime, registry, ingress and DNS.
      providers: [aws, mock]
    - name: data
      description: Relational database.
      providers: [aws, azure, mock]
    - name: storage
      description: Object storage.
      providers: [aws, oci, mock]
  resources:
    - id: network
      type: network
      availabilityZones: 2
    - id: registry
      type: container-registry
      implementation: ecr
    - id: api
      type: compute.container-service
      implementation: ecs-fargate
      image: catalog://sample-api
      replicas: 2
      cpu: 0.5
      memoryMiB: 1024
      port: 8080
      public: true
      healthCheckPath: /health
    - id: worker
      type: compute.container-service
      implementation: ecs-ec2
      image: catalog://sample-worker
      replicas: 1
      cpu: 0.5
      memoryMiB: 1024
      critical: false
    - id: database
      type: database.postgresql
      placement: data
      size: small
      storageGiB: 50
      highAvailability: zone-redundant
      backup: { enabled: true, retentionDays: 7 }
    - id: storage
      type: object-storage
      placement: storage
      tier: standard
      versioning: true
    - id: ingress
      type: ingress
      routes:
        - service: api
    - id: dns
      type: dns
      target: ingress
  connectivity:
    - { from: api, to: database, protocol: postgres, port: 5432, mode: private-preferred }
    - { from: worker, to: database, protocol: postgres, port: 5432, mode: private-preferred }
    - { from: api, to: storage, protocol: https, mode: secure }
  observability: { logs: true, metrics: true, traces: true, uptime: true, alerts: true }
```

## Validating from your machine

```bash
curl -X POST "$ORK_API_URL/api/v1/templates/validate" \
  -H "Authorization: Bearer $ORK_TOKEN" -H "Content-Type: application/json" \
  --data "$(jq -Rs '{source: ., planCode: "GROWTH"}' < template.yaml)"
```
