The API and the worker read the same typed configuration (`packages/runtime/src/config.ts`) and
**refuse to start** on invalid values, listing every problem. In local development a `.env` file at
the repository root is loaded (`cp .env.example .env`); real environments inject variables.

Booleans accept `true`, `false`, `1` or `0`.

## Core

| Variable | Type | Default | Description |
|---|---|---|---|
| `NODE_ENV` | `development` \| `test` \| `production` | `development` | Production enables `Secure` cookies and the production safety checks below. |
| `DATABASE_URL` | URL | **required** | Postgres connection string, e.g. `postgresql://platform:platform@localhost:5432/platform`. |
| `REDIS_URL` | URL | **required** | Redis for queues and concurrency slots, e.g. `redis://localhost:6379`. |
| `API_PORT` | integer | `4000` | Port the API listens on. |
| `API_PUBLIC_URL` | URL | `http://localhost:4000` | Public URL of the API. |
| `WEB_PUBLIC_URL` | URL | `http://localhost:3000` | Public URL of the console. OIDC redirect URIs are built from it. |
| `SESSION_SECRET` | string, ≥ 32 chars | **required** | Signs session and OIDC-flow cookies. Must not start with `change-me` in production. |
| `LOG_LEVEL` | `trace` … `fatal` | `info` | Pino log level. Tokens, secrets, cookies and authorization headers are always redacted. |

## Authentication

| Variable | Type | Default | Description |
|---|---|---|---|
| `AUTH_DEV_LOGIN_ENABLED` | boolean | `false` | Enables `POST /auth/dev-login` (email only). **Startup fails** if `true` with `NODE_ENV=production`. |
| `OIDC_<KEY>_ISSUER` | URL | | Issuer of an OIDC provider; `<KEY>` is any uppercase name. |
| `OIDC_<KEY>_CLIENT_ID` | string | | Client id at that provider. |
| `OIDC_<KEY>_CLIENT_SECRET` | string | | Client secret. |

### Single sign-on (OIDC)

A provider is enabled when all three `OIDC_<KEY>_*` variables are set (and the issuer contains no
`<placeholder>`). `ENTRA`, `GOOGLE` and `GITLAB` get friendly names; any other key is shown as is.
Register this redirect URI at the provider:

```text
<WEB_PUBLIC_URL>/api/v1/auth/oidc/<key>/callback      # key in lowercase, e.g. /oidc/entra/callback
```

```bash title="Microsoft Entra ID"
OIDC_ENTRA_ISSUER=https://login.microsoftonline.com/<tenant-id>/v2.0
OIDC_ENTRA_CLIENT_ID=<application id>
OIDC_ENTRA_CLIENT_SECRET=<client secret>
```

The flow uses authorization code with PKCE (S256), and verifies `state` and `nonce`. Accounts link only
by provider-verified email. Microsoft Entra ID is the reference provider; Google and GitLab work by
configuration but are less tested. GitHub needs an OAuth (non-OIDC) adapter that does not exist yet.

## Worker and OpenTofu runner

| Variable | Type | Default | Description |
|---|---|---|---|
| `WORKER_CONCURRENCY` | integer 1–64 | `4` | Deployment jobs processed in parallel by one worker. |
| `HEALTH_CHECK_INTERVAL_SECONDS` | integer ≥ 10 | `30` | Health monitor tick. |
| `DRIFT_CHECK_INTERVAL_MINUTES` | integer ≥ 0 | `360` | Drift scan interval on real providers (one OpenTofu plan per applied resource). `0` disables it. |
| `TOFU_IMAGE` | string | `ghcr.io/opentofu/opentofu:1.12.7` | Runner container image. |
| `TOFU_MODULES_DIR` | path | | Module library on the worker host, mounted read-only into runners. |
| `TOFU_MODULES_IN_IMAGE` | boolean | `false` | Modules are baked into `TOFU_IMAGE`; nothing is mounted. |
| `TOFU_WORK_DIR` | path | | Where the worker writes per-resource working directories. |
| `TOFU_WORK_VOLUME` | string | | Containerized worker: a named volume mounted at `TOFU_WORK_DIR`, passed to runners. |
| `TOFU_PLUGIN_CACHE_VOLUME` | string | `orkstage-tofu-plugins` | Named volume shared by runners as the provider plugin cache. |
| `TOFU_DOCKER_NETWORK` | string | | Docker network for runner containers (to reach an emulator by name). |
| `TOFU_TIMEOUT_MINUTES` | integer 1–240 | `45` | Hard limit for one OpenTofu command. |
| `AWS_EMULATOR_ENDPOINT` | URL | | Emulator endpoint as reachable from inside containers, e.g. `http://ministack:4566`. |

## Secrets and integrations

| Variable | Type | Default | Description |
|---|---|---|---|
| `SECRETS_AWS_REGION` | string | `us-east-1` | Default region for `aws-sm://` references given by name (ARNs carry their own region). |
| `SECRETS_AWS_ENDPOINT` | URL | | Secrets Manager endpoint override, for emulators, as reachable from the API and worker. |
| `ENCRYPTION_KEY` | base64, 32 bytes | | Encrypts secrets the platform must read back (webhook signing secrets). **Required in production.** Generate with `openssl rand -base64 32`. |
| `WEBHOOK_ALLOW_PRIVATE` | boolean | `false` | Allow `http://` and private-network webhook URLs. Local development only; **refused in production**. |

See [Secret references](/docs/self-hosting/secrets/).

## Console

| Variable | Default | Description |
|---|---|---|
| `API_INTERNAL_URL` | `http://localhost:4000` | API origin (no path) that the console proxies `/api/*` to, e.g. `http://api:4000`. Rewrites are resolved when the console is built, so set it at build time. |

## Production safety checks

With `NODE_ENV=production` startup fails when:

- `AUTH_DEV_LOGIN_ENABLED` is true;
- `ENCRYPTION_KEY` is missing;
- `WEBHOOK_ALLOW_PRIVATE` is true;
- `SESSION_SECRET` still starts with `change-me`.
