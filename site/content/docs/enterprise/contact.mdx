---
title: Contact
description: How to reach the OrkStage team about Enterprise, security reports and community questions.
---

| Topic | Where |
|---|---|
| Enterprise, licensing, partnerships | [hello@orkstage.io](mailto:hello@orkstage.io) |
| Security vulnerabilities (private) | [security@orkstage.io](mailto:security@orkstage.io) |
| Questions, ideas, help | GitHub Discussions on [orkstage/orkstage](https://github.com/orkstage/orkstage) |
| Bugs | GitHub Issues on the repository concerned |

When you write about Enterprise, tell us roughly how many instances and organizations you plan to
run, which clouds, and which identity provider you use. That is enough to start.

Please report security problems privately, never in public issues. See
[Security hardening](/docs/self-hosting/security/#reporting-a-vulnerability).
