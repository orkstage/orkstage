---
title: Contact
description: How to reach the OrkStage team about Enterprise and licensing, private security reports, community questions and bugs.
---

| Topic | Where |
|---|---|
| Enterprise, licensing, partnerships | [hello@orkstage.io](mailto:hello@orkstage.io) |
| Security vulnerabilities (private) | [security@orkstage.io](mailto:security@orkstage.io) |
| Questions, ideas, help | GitHub Discussions on [orkstage/orkstage](https://github.com/orkstage/orkstage) |
| Bugs | GitHub Issues on the repository the bug belongs to |

When you write about Enterprise, tell us three things: roughly how many instances and organizations
you plan to run, which clouds you use and which identity provider you use. That is enough to start.

Report security problems privately, never in public issues. See
[Security hardening](/docs/self-hosting/security/#reporting-a-vulnerability).
